# Group cover artwork

`subject-covers-v1.webp` contains six short decorative banners cropped from the original TEDVIO design generated and approved by the owner in October 2026. It contains no institutional logos, names, interface text or student data. No third-party stock provider is contacted at runtime.

280 × 480 px WebP sprite, six 280 × 80 rows: anatomy, pharmacology, embryology, clinical examination, pharmacokinetics and physiology. The imagery is decorative, not a diagnostic or teaching diagram. Logos and all academic values are rendered separately from the existing account data. Unknown subjects use the neutral CSS fallback.
